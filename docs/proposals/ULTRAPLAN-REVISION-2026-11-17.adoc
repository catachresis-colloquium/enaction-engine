== ADR-0025: independence by formalism (design sketch)

The owner's ruling: the specification that the reducer must pass is a
mechanised reference semantics, written and proved before any reducer
design, in Rocq and in Agda, cross-checked.

* *Shape.* One prose statement of the reduction contract (CAC-KERNEL
  section 2 and the rung-4 and rung-6 laws). Two mechanisations of it:
  `Reducer.v` and `Reducer.agda`. Each defines the state, the step over
  ordered events, and the expected beliefs of each scenario.
* *Cross-check.* Rocq extracts the expected beliefs of every scenario to
  `conformance/esm/v1/independent/`. Agda computes the same values by
  normalisation. A gate requires byte-equal output. A disagreement is a
  finding about the prose, not a tie to break.
* *Where independence comes from.* The owner declined the "different
  author" route, so the two mechanisations share an author unless care is
  taken. Proposed: two sessions with no shared context each write one
  mechanisation from the prose alone. That is N-version specification, with
  the provers as referees.
* *What it does not give.* Two formal models can agree and both misread the
  intent. The prose statement stays the owner's to accept.
* *Chronology gate.* As Q4 required: both mechanisations and the vectors are
  merged before the first reducer-design pull request is created, read from
  the forge API.
* *Experiment first.* Before the full semantics: mechanise only "holds at a
  tick" and the model timeline (CAC-KERNEL section 9), extract the timelines
  of the 7 accepted `conformance/tom/v1` cases, and compare them with the
  hand-written `expected.json` files. If extraction or the byte comparison
  is impractical, ADR-0025 changes before it is accepted.
