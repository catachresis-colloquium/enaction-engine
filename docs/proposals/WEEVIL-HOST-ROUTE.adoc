== Why this route

These facts were measured on 2026-11-14.

* Enaction has 5 library crates and no binary, no tick and no consumer. The
  default members pass 126 tests.
* The observer leak is present at `crates/enaction-trace/src/store.rs:325`.
  The optional digest is present at
  `crates/enaction-contracts/src/package.rs:162`.
* Evil Weevil has a frozen C ABI (1.0), an integer kernel and 3 injection
  modes. Its kernel passes 32 of 32 tests with Zig 0.16.0.
* IDApTIK has an adapter for that kernel (`crates/idaptik-weevil`) and a
  headless runner, `idaptik-weevil-replay`, with a deterministic corridor
  world and a JSON replay.
+
*Correction, 2026-11-14.* The first version of this line said that IDApTIK
"already runs its guard on that kernel". That was an overclaim, taken from
documents and not from a build. Work package B1 found that the adapter crate
did not compile on IDApTIK `main` (17 errors) and that no CI job built it.
B1 repaired the crate; with the repair, 581 tests pass with the kernel
linked. Until that repair is merged, the kernel has an adapter and no
running host.
* IDApTIK has no `package-runner`. The supervisor ledger that the earlier plan
  reports on does not drive the guard. The six-stage `CacTrace` is 6
  constants.
* Affect exists only in Project Ovine's JavaScript mockup, which uses a
  variable time step and `Math.random`.
* Evil Weevil does not mention Enaction anywhere.

Conclusion: Enaction has a mind contract and no body. Evil Weevil has a body
and a thin mind. One game has an adapter for that body (see the correction
above).

The rules of the earlier architecture stay in force:

* No layer links another as a library, except that a host links the Evil
  Weevil kernel through its C ABI.
* Every seam is a process or a versioned document.
* A missing binary is a failure. No stub runs outside tests.

=== The licence boundary

Enaction code is AGPL-3.0-or-later. Evil Weevil code is MPL-2.0, and its
`AGENTIC` record denies AGPL. Therefore no Enaction source enters Evil
Weevil. The mind crosses the boundary as contract documents and conformance
bytes only. Evil Weevil implements the mind in its own integer Zig code and
proves conformance against Enaction's fixtures.

This also answers the composition question. A closed engine can load the
MPL kernel in process. It can then emit Enaction documents and run
`enaction-validate` as a separate program. No party must link AGPL code into
a game. This plan makes no licence edit. Licence edits stay manual and
owner-only.

== Mind slice 1

=== Rules that bind every mind

These rules come from ADR-0014, ADR-0015 and ADR-0016. They bind Evil Weevil
because it conforms to the Enaction contract.

. No float in the mind. All state is integer or fixed point.
. Affect buys attention, never belief. Affect can change how often an agent
  samples, how long it remembers and how fast it moves. Affect cannot assert
  a proposition.
. Utilities never leave the conative layer. A mind publishes a *ranking* of
  candidates and the selected candidate. It never publishes a score.
. A change of affect token is an event. It carries the identifier of the
  event that caused it.
. A contradiction is the pain signal. It produces a bounded arousal spike.

=== The four effects

[cols="2,4,3,1",options="header"]
|===
| Effect (R4) | Mechanism | Home | Slice

| Wrong for a reason
| The agent acts on a remembered bearing after the target moved, or on a
  decoy. The report shows the belief, the world truth, the divergence and the
  events behind the belief.
| Exists in the kernel (memory, ADR-0009) and in the IDApTIK corridor world
  (decoys). Slice 1 only reports it.
| 1

| Ill will that persists
| A *grievance* reservoir for each remembered target. Harm from that target
  fills it. It drains much more slowly than memory expires. It widens the
  margin that a challenger must beat. The agent then keeps a pursuit that the
  ranking no longer supports.
| New in the kernel. Needs the host capability `EE_CAP_DAMAGE_EVENTS`.
| 1

| Bodily tells
| An *arousal* reservoir. A surprise fills it. It changes the motor output
  before the decision changes: a one-tick freeze (startle), a delay before a
  new action (hesitate), and a locked gaze (fixate).
| New in the kernel. Reported through intent flags.
| 1

| It models you
| A first-order belief about the player: "the player knows where I am". The
  host reports whether a contact observes the agent. The agent remembers it
  and chooses ambush or open pursuit from it. The belief can be false.
| New snapshot input and new belief state. Uses the ascription path
  `[agent, player]`.
| 2
|===

Slice 1 delivers 3 effects. "It models you" is slice 2, because it needs a new
host input and a second belief store in the kernel.

=== The definition that makes ill will checkable

A tick shows *commitment override* when the selected candidate is the
incumbent and is not first in the published ranking. The validator checks this
definition. A designer can then count the ticks on which an agent acted from
commitment and not from the ranking. This is the measurable form of "ill will
that persists".

=== Affect state in the kernel

Three reservoirs, each a fixed-point value from 0 to full scale:

[cols="1,3,3",options="header"]
|===
| Reservoir | Filled by | Effect

| arousal | A new contact at close range, a contradiction, damage
| Tells. Longer memory. It does not change belief.

| fear | Low health, several threats, no ammunition
| Raises the rank of evade. Shortens hesitation before flight.

| grievance | Damage from one remembered target
| Widens the commitment margin for that target.
|===

Each reservoir is a leaky integrator in integer arithmetic:
`x' = x - (x >> k) + input`, clamped. The affect token is the reservoir with
the highest value above a threshold, in declaration order on a tie, with a
hysteresis band. The Evil Weevil decision record fixes `k`, the thresholds
and the band, and pins them with digests.

=== ABI

The change is additive, so it is ABI 1.1 under Evil Weevil ADR-0005. The
existing `ee_tick` does not change, and its 3 pinned digests must not move.
That is the acceptance test, as in ADR-0010. New caller-owned state and a new
trace record enter through a new entrance. A host that does not call the new
entrance gets the 1.0 behaviour exactly.

== The mind trace contract

`enaction-mind-trace/1` is a separate versioned document. It stays outside
`enaction-runner-output/1` so that the strict envelope gains no optional
field. Integers only. Canonical bytes are RFC 8785 JCS (Q1).

[source,json]
----
{
  "contract": "enaction-mind-trace/1",
  "producer": {"kernel": "evil-weevil", "abi": "1.1"},
  "profile": {"id": "idaptik", "version": "1.0.0"},
  "vocabulary": {
    "affect_tokens": ["calm", "wary", "afraid", "angry"],
    "candidates": ["advance", "investigate", "engage", "evade", "reload"],
    "tells": ["hesitate", "startle", "fixate"]
  },
  "ticks": [
    {
      "tick": 41,
      "agent": "guard-0",
      "affect": {"token": "angry", "attention": 7500, "caused_by": [17]},
      "conation": {
        "ranking": ["evade", "engage", "advance"],
        "incumbent": "engage",
        "selected": "engage",
        "target": "contact-3"
      },
      "tells": ["fixate"]
    }
  ]
}
----

The validator refuses a document with a named rule when:

* the contract tag differs, or a field is unknown (`UnknownField`);
* a token, candidate or tell is not in the declared vocabulary
  (`UndeclaredTerm`);
* a vocabulary is empty or has a duplicate (`BadVocabulary`);
* ticks are not strictly increasing for one agent (`NonMonotonicTick`);
* a ranking is empty or has a duplicate, or `selected` is not in the ranking
  (`BadRanking`);
* `selected` is neither first in the ranking nor equal to `incumbent`
  (`UnexplainedSelection`);
* `attention` is above full mass (`MassOutOfRange`);
* an affect token differs from the previous tick's token for that agent and
  `caused_by` is empty (`UncausedAffectChange`);
* an identifier in `caused_by` is absent from the paired runner output
  (`DanglingCause`);
* an integer is above 2^53-1 (`IntegerOutOfRange`).

The report derives commitment override from the document. The producer does
not assert it.

== Orchestration rules

. *Models.* The advisor designs contracts and decision records and reviews
  gates. Opus implements one package for each session. Sonnet reads, writes
  tests against a fixed specification and makes mechanical changes. Haiku does
  CI, workflow and status upkeep.
. *One coordinator for each repository.* A1 and A2 share enaction-engine.
  They own disjoint crates. Neither edits `Cargo.toml`, `Justfile` or a
  workflow. The coordinator applies those edits and resolves `Cargo.lock`.
. *Tests first.* Each session writes the failing test or the planted control
  before the change.
. *No silent pass.* A step whose toolchain is absent is reported as not run.
  It is never reported as passed.
. *Stop conditions.* A session stops and reports when a gate needs an owner
  ruling, when it must edit a file that another package owns, or when a
  licence header would change.
. *Draft pull requests only.* Nothing merges without the owner.

== Evidence discipline for the psychology

The mechanisms above are design hypotheses. They are not findings. These
sources are leads for the theory document. No source was checked in this
session, so none is cited as evidence:

* appraisal theory (Lazarus; Scherer) for affect as an evaluation of events
  against goals;
* action tendencies (Frijda) for affect that prepares movement before choice;
* anger as an approach-related affect (Carver and Harmon-Jones) for
  grievance that drives pursuit;
* intention as commitment (Bratman) for a plan that resists reconsideration;
* mind perception and the uncanny (Gray and Wegner) for unease caused by an
  apparent capacity to feel;
* the attribution of intent to simple motion (Heider and Simmel).

A claim about animals or people does not transfer to a game agent without an
argument. The theory document must state each commitment and what would
falsify it.
