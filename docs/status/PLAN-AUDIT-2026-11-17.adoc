== Method

Every command ran from the root of the repository on commit `cdf7ca1`, which
is the head of `main` when the audit started. `3bf55cd` is an ancestor of
that commit. Each command ran through `bash -c` with a 15-minute cap; no
command reached the cap. Commands were run as written in the `done_when`.
Where a `done_when` joins commands with `&&` and an earlier command failed,
each later command was run on its own, and its row says so.

Tools absent from this container: `just`, Agda, Coq (`coqc`), Idris2, Zig,
Lean, Verus and Creusot. Nothing was installed. Steps 5, 6 and 7 belong to
other repositories, and those repositories were not cloned.

Where a `done_when` is a condition in prose rather than a command, the row
names the check that was run in its place.

  `package.rs`. Commit `51a9aa4` removed the parameter, and step 11 is the step
  that removes it by design, so the absence is not a gap. The command does not
  check that a mandatory `computed_digest: &str` exists, and no commit in the

  4a. Its input file is written by the test that 4a could not run.
* `ULTRAPLAN-REVISION-2026-11-17` records steps 1 to 3 and 11 as landed as
  work packages A1 and A2, and it says that their `done_when` commands were
  not all re-run. This audit re-ran them. A1 and A2 pass their own
  `done_when` (rows A1.1 to A2.3). Step 11's wider `done_when` fails (rows 11a
  and 11b). A2's scope, as the Weevil route states it, covers only the mind
  trace validator and step 3, not step 11's full list.
* Row 10c checks the tree, not the workflow run history on GitHub, so a
  `conformance-time` run that exists elsewhere would not change this row.
